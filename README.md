# 🚀 Veridict – AI-Powered Online Judge Platform

Veridict is a full-stack MERN-based Online Judge Platform that enables users to solve coding problems, participate in coding contests, view leaderboards, and receive AI-powered code reviews. The platform supports code execution in **Python, C, C++, and Java**, providing automated testcase evaluation and real-time verdicts.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/Tushalijain/Veridict.git
```

---

## Backend Setup

```bash
cd backend
npm install
npm run dev
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

# 🔑 Environment Variables

## Backend (.env)

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key

OPENROUTER_API_KEY=your_openrouter_api_key
```

---

## Frontend (.env)

```env
VITE_API_URL=http://localhost:5000/api
```

For production:

```env
VITE_API_URL=https://veridict-backend-2l6y.onrender.com/api
```
